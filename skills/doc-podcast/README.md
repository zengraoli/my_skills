# doc-podcast：文档 → 双人播客（SenseAudio A1）

给 coding agent 用的 skill：给它一份文档、一个链接或一个主题，agent 读完写成两位主播的对谈脚本，`podcast.py` 用 SenseAudio 的多角色音频生成接口渲染成播客 mp3，附带按说话人的 srt 字幕，可外挂背景音乐。相当于自己搭的 NotebookLM Audio Overview。所有 AI 环节走 SenseAudio 接口，本地只有 ffmpeg 做拼接混音。

```
素材 ──► 提炼话题 ──► 对谈脚本 ──► podcast.py render ──► mp3 + srt
        (agent)      (agent)        (A1 分段生成 → ffmpeg 拼接 → 可选 BGM 压混)
```

## 怎么用

**在 agent 里用自然语言说需求即可，不需要记参数。** agent 会读 `SKILL.md` 自己走流程：检查环境 → 读素材 → 写脚本 → dry-run 看预算 → 渲染 → 把 mp3、srt 路径和费用给你。

```
把这篇文章做成一期 5 分钟的双人播客：D:\docs\xxx.md
用 https://…… 这个页面做一期对谈，男主持女嘉宾，配轻快一点的背景乐
做一期讲 loop 命令的播客，10 分钟
```

- Claude Code：直接说，或 `/doc-podcast <素材>` 强制触发。
- Codex / Kimi Code / grok-cli 等：装好 `.agents/skills/` 后直接说需求。
- 想换主播音色、时长、背景乐，直接在需求里说。

下面的脚本命令是给**手动运行或调试**用的，日常不需要。

## 目录

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 给 agent 的流程：读素材、写脚本的规矩、渲染、验收 |
| `podcast.py` | 渲染脚本：解析对谈脚本 → 分段调 A1 → 拼接 → srt → 可选 BGM |
| `.env` | key 与默认配置（模型、分段字数、ffmpeg 路径） |
| `README.md` | 本文件 |

## 依赖

Python ≥ 3.9 + `requests`；ffmpeg + ffprobe（Windows 从 https://www.gyan.dev/ffmpeg/builds/ 下载解压，把 bin 目录填进 `.env` 的 `FFMPEG_DIR`）；SenseAudio API key（https://senseaudio.cn ，填进 `.env`）。跑 `python podcast.py check` 逐项验证。

## 用法

```bash
python podcast.py check
python podcast.py render --script 脚本.txt --dry-run                 # 看分段、预计时长与费用，不花钱
python podcast.py render --script 脚本.txt                           # 渲染，输出 output/podcast/<标题>.mp3 + .srt
python podcast.py render --script 脚本.txt --bgm bgm.mp3 --bgm-gain -18 --bgm-intro 2.5
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--script` | 必填 | 对谈脚本文件，格式见下 |
| `--title` | 脚本里的 `# 标题` | 输出文件名 |
| `--out-dir` | `output/podcast` | 输出目录 |
| `--chunk-chars` | `.env` 的 `CHUNK_CHARS`（450） | 每段最多字数；450 字 ≈ 95 秒，上限 120 秒 |
| `--bgm` | 脚本里的 `# 背景音乐：` | `无` / `生成[：风格描述]`（调用同级 music-gen 生成 120 秒纯音乐，约 0.5 元，已有则复用）/ 文件名（先当前目录、再项目根 `input/` 里找）；有音乐时循环播放、压低、随人声闭音、结尾淡出 |
| `--bgm-gain` | `-18` | 背景音乐音量（dB） |
| `--bgm-intro` | `2.5` | 人声进入前的纯音乐秒数 |
| `--reuse-chunks` | — | 分段目录里已有且提示词未变的段直接复用，不重复扣费（换 BGM、改混音参数时用） |
| `--dry-run` | — | 只打印分段与第 1 段提示词 |

## 脚本格式

```
# 标题：让AI替你值夜班
# 角色：小满=female_0038_b|主持人，亲切、语速略快
# 角色：阿川=male_0029_a|嘉宾，沉稳、爱举例
# 场景：两人在安静的播客录音室对谈

小满：（热情）大家好，欢迎收听今天的节目。
阿川：（笑）简单说，它能让 AI 自己定闹钟。
```

- `# 角色：名字=音色id|性格描述`，最多 3 个；音色表与试听 https://docs.senseaudio.cn/guides/voice/catalog 。
- 每行"角色名：台词"，一行只写一个人；括号里是情绪/语气提示，不会被念出来。
- `# 背景音乐：无 | 生成 | 生成：轻快电子 | 文件名.mp3`。自备文件放到项目根目录的 `input/`，脚本会去那里找；选"生成"需要同级目录有 music-gen skill（同一仓库里），没有会提示安装。
- 可选 `# 音乐：描述`，会把 `[背景音乐]` 写进 A1 提示词——实测只会零星加装饰音，稳定背景乐请用上面的 `# 背景音乐：`。

## 价格

A1 按生成秒数计费，0.017 元/秒（85 积分/秒）：5 分钟 ≈ 5 元，10 分钟 ≈ 10 元。实测 4.7–5.1 字/秒，一段 450 字约 90 秒、1.5 元。

## 目前能做到的（2026-09-12 实测）

- **两位主播音色全程锁定**：`@音色id` 绑定角色，3 段实测 38 句字幕逐句基频与脚本的男女顺序全部一致；分段生成时每段带同一份角色定义，跨段不串音。
- **标记不会被念出来**：`{speaker：xx}`、`@音色id`、括号情绪词都被正确理解（这一点和平台的音乐模型完全不同）。
- 单段最长 120 秒，脚本自动按 450 字分段拼接，任意长度。
- 字幕：每句毫秒级起止 + 逐字时间，脚本按台词顺序标上说话人生成 srt。
- 外挂背景音乐：前奏、压低、跟随人声闭音（sidechain）、结尾淡出，全部 ffmpeg 本地完成。
- 情绪/语气提示有效：`（笑）`、`（好奇）`、`（放慢）` 会体现在演绎上。

## 目前做不到的，以及为什么

| 需求 | 现状 | 原因 |
|---|---|---|
| **模型自带背景音乐** | 不可靠 | `[背景音乐]` 标签实测：不会生成片头纯音乐前奏，对白中段基本无音乐，偶尔在结尾加一个钢琴收尾音。所以背景乐一律外挂 |
| **一次生成超过 120 秒** | 分段 | 接口硬上限；分段后段间有 0.5 秒静音，语气在交界处可能有细微变化 |
| **字幕自带说话人** | 靠对齐 | 接口不返回说话人，按脚本行顺序匹配；一行里混两个人的话会归错 |
| **用自己的声音当主播** | 未接入 | 接口支持参考音频（`@音频1`，≤30 秒，最多 3 段）和平台克隆音色，本 skill 第一版只用系统音色；需要再加 |
| **音效（笑声、翻页声等）** | 未接入 | `[音效]` 标签行为同背景音乐一样不稳定；要音效用 SenseAudio 音效接口单独生成后叠加 |
| **超过 3 位角色** | 不行 | 平台限制：音色标签 + 参考音频合计 ≤ 3 |
